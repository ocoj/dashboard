# NetBrid Web UI 全量汉化排查 — 逐页逐项

## 任务目标

对 `https://nb.lanxun.pro:30443` 的每一个页面、子页、按钮、弹窗、Tab 进行系统性中文汉化排查，
记录所有仍显示英文的文本，按汉化 SOP 完成翻译。

## 前置准备

1. 设置 cookie `NEXT_LOCALE=zh` 切换到中文（每个页面刷新后都要确认）
2. 准备一个清单文件 `/tmp/missing-i18n.txt` 记录所有发现的英文文本
3. 格式：`[菜单/页面] [位置] 英文原文`，如 `[Settings/Authentication] Switch标签 "Session Expiration"`

## 排查规则（严格按此执行）

### 范围
- **每个主菜单** 的每个子页面
- **每个页面** 的标题、描述文本、按钮文字、表格列头、筛选器标签、空状态提示
- **每个弹窗/Modal** 的每个 Tab（弹窗内 Tab 各点一遍）
- **每处 Tooltip**（鼠标悬停才能看到，必须逐个悬停检查）
- **每个下拉选项**、**placeholder**、**表单字段标签**
- **开关（Toggle/Switch）的标签和描述文字**
- **Breadcrumb 导航文字**
- **侧栏菜单项**
- **通知 Toast 文字**
- **确认对话框文字**
- **所有按钮：主按钮、次要按钮、图标按钮的 tooltip、操作菜单项**

### 不需要检查的
- API 返回的动态数据（如 peer 名称、用户邮箱、IP 地址）
- 公告横幅 `AnnouncementBanner`（后端动态内容）
- 浏览器控制台日志

## 发现英文文本后的处理

每积累 20-30 条记录后，暂停排查，执行汉化：

1. 打开对应的源文件
2. 在 `zh-map.ts` 中查是否已有翻译（`grep "'English Text'" src/i18n/zh-map.ts`）
3. 没有 → 按字母序插入 `'English Text': '中文翻译',`
4. 源文件中用 `<TransText>` 包裹对应文本（如果尚未包裹）
5. `npx tsc --noEmit` 确认零错误
6. 继续排查下一批

## 完成后

1. `npx tsc --noEmit` 最终检查
2. `npx next build` 构建
3. 部署到 OMV（只更新镜像，不动其他）
4. 浏览器重新遍历，逐条勾销 `/tmp/missing-i18n.txt` 中的记录
5. 确认汉化生效 + 页面功能正常
