## 标准工作流

```
1. 修改源代码 → 加 import { TransText } 或 import zhMap
2. npx tsc --noEmit   # 必须零错误
3. npx next build
4. 部署到 OMV（见下方）
5. 浏览器验证：确认汉化生效 + 页面功能正常
```
