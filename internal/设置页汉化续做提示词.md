## 工具说明

### zh-map.ts
路径：`src/i18n/zh-map.ts`
格式：`'English Text': '中文文本',`
需排序插入，直接手改。

### TransText 组件
```tsx
import { TransText } from "@/i18n/trans-text";

// 包裹 JSX children
<Button><TransText>Add Peer</TransText></Button>

// 包裹 Label 内容
<Label><TransText>SSH Access</TransText></Label>
```

### 注意事项
- `copyText` 等 `string` 类型 prop **不能**传 JSX，保持字符串原样
- `description`、`placeholder` 等字符串 prop 同上
- 注意 import 引号一致（" 还是 '）
- 改完一个文件后 `npx tsc --noEmit` 检查类型错误

## 工作流
1. 开 `https://nb.lanxun.pro:30443`，设置 `NEXT_LOCALE=zh` cookie
2. 逐页面遍历，记录英文文本
3. 在 `zh-map.ts` 查是否已有翻译，没有则添加
4. 在源文件中用 `<TransText>` 包裹对应文本
5. TypeScript 检查 → 构建 → 部署 → 验证
